# Atajos de teclado

## Archivo

| Atajo | Acción |
|---|---|
| Ctrl+N | Nuevo proyecto |
| Ctrl+O | Abrir proyecto |
| Ctrl+S | Guardar (confirma; los cambios ya se guardan automáticamente) |
| Ctrl+Shift+S | Guardar copia como… |
| Ctrl+W | Cerrar proyecto |
| Ctrl+I | Importar tablas (CSV/Excel) |
| Ctrl+E | Exportar mapa 2D como PNG |
| Ctrl+Shift+E | Exportar vista 3D como PNG |
| Ctrl+R | Reporte de secciones (Excel) |
| Ctrl+Shift+C | Copiar mapa 2D al portapapeles |
| Ctrl+Q | Salir |

## Edición y mapa

| Atajo | Acción |
|---|---|
| Enter | En la entrada: agregar la relación (en Sección A pasa a Sección B) |
| C | Activar / desactivar el modo Conectar |
| Alt + arrastre | Conectar sin activar el modo |
| R | Invertir la dirección de la flecha seleccionada |
| Esc | Cancelar el arrastre de conexión, salir del modo o quitar la selección |
| Supr | Eliminar la selección (secciones o relaciones, con confirmación) |
| Ctrl+A | Seleccionar todo |
| Flechas / Shift+Flechas | Mover la selección 1 px / 10 px |
| Doble clic en flecha | Agregar punto de quiebre |
| Doble clic en nodo | Editar sección |
| Ctrl+Shift+N | Nueva sección personalizada |

## Vista

| Atajo | Acción |
|---|---|
| Rueda del mouse | Zoom |
| Ctrl+0 | Ajustar a la vista |
| Ctrl+1 | Zoom 100 % |
| Ctrl++ / Ctrl+- | Acercar / alejar |
| Botón central o Espacio + arrastre | Desplazar la vista |
| F4 | Mostrar u ocultar el panel MasterFormat |
| F6 | Mostrar u ocultar avance y responsables |
| F1 | Manual de uso (tema de la pestaña activa) |
